# SDN_Group4

Custom File Encryption Tool 
Group 4 

Problem Statement 
Users often store sensitive files that can be accessed by unauthorized people. The proposed 
system will provide a simple way for users to select a file, encrypt it using a custom encryption 
algorithm, and decrypt it when needed. The system will help protect the confidentiality of files 
while demonstrating Java programming, object-oriented design, file handling, and encryption 
concepts.
